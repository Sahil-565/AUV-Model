# Sparus AUV MATLAB/Simulink Model

This repository contains a MATLAB/Simulink model and related scripts for the Sparus underwater vehicle project.

## Contents
- MATLAB scripts for model parameters, plotting, and simulation
- Simulink model file
- MATLAB live scripts for matrix and drag-force calculations
- Report files and result graphs

## Main files
- `Sparus_3D_advance_model.mdl`
- `Parameters.m`
- `RovModel.m`
- `Plotting.m`

## Notes
Generated/cache files such as `slprj`, `.slxc`, and compiled binaries are excluded from this repository.
